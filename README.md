# Retail Sales Exploratory Data Analysis

## About the Project

This project was completed individually as part of my Data Analytics studies.

The objective of the project was to perform Exploratory Data Analysis (EDA) on retail sales data using Python and Pandas.

The project involved working with Sales, Invoice and Product datasets to prepare, combine, analyse and visualise the data.

## Tools & Technologies

- Python
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook / Microsoft Fabric

## What I Did

- Loaded the Sales, Invoice and Product datasets
- Checked the datasets for missing values
- Created a Sales column using Quantity and Unit Price
- Merged the Sales and Invoice datasets using `InvoiceNo`
- Merged the result with the Product dataset using `StockCode`
- Used summary statistics to explore the data
- Filtered and analysed the dataset
- Checked the data for outliers
- Analysed sales by product category and country
- Created a pivot table for further analysis

## Data Visualisations

I created several visualisations during the analysis, including:

- Scatter plots
- Histogram
- Sales over time chart
- Correlation heatmap
